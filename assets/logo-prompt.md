# 圖標設計描述

使用內建 `image_gen` 工具生成；保存原始 PNG，未重繪或覆蓋生成原圖。Windows ICO 僅做格式轉換與尺寸縮放，保留透明通道。

用途：SC2TC-Renamer 的 Windows 執行檔圖標及程式內品牌標記。

設計描述：

> A Windows desktop application icon for an offline Chinese filename conversion tool: a cobalt-blue rounded-square tile on a transparent canvas, overlapping white document cards, a teal conversion arrow, and the Chinese glyph 文. Designed for legibility at small sizes with balanced proportions, restrained depth, and a Windows 11 visual style. No wordmark or surrounding objects.
